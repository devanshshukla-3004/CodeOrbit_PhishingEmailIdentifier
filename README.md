# CodeOrbit Phishing Email Identifier

Cyber Security Internship project for CodeOrbit Tech.

The report analyzes five fictional emails: four phishing examples and one legitimate control. It identifies suspicious domains, urgency, credential/payment requests, secrecy, suspicious links, and other red flags.

See `Phishing_Email_Identifier_Report.docx` and `media/` for the full evidence package.
